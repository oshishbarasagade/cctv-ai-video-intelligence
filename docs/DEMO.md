# Demonstration Flow

A tight, ~3-minute walkthrough for a presentation.

## Fastest path — instant demo
1. Open **http://localhost:5173** → **Sign in** → **Try a live demo**.
2. Subli creates a throwaway account, generates a synthetic surveillance clip,
   runs the full pipeline, and drops you into the **Analysis Workspace**.

## Full guided flow
1. **Landing** → "See what your videos say."
2. **Sign up** → **Onboarding** (name → use-case → experience).
3. **Dashboard** — metrics + analytics charts.
4. **New Analysis** → create *"Campus Entrance Analysis"*.
5. **Upload** a CCTV clip → watch **real staged processing**
   (metadata → sampling → detection → ocr → captioning → events → subtitles).
6. **Open Analysis Workspace**:
   - Play the video; the **event timeline** shows markers — click one → video
     seeks to that exact moment.
   - Left panels: **Events / Objects / People / OCR / Search**.
   - **Search** "person near entrance" → click a result → seeks.
   - **Ask Subli**: "What happened?" → grounded answer with clickable timestamps.
     **Find the Story** → chronological narrative.
   - **Add evidence** on a key frame; **Report** → download the **PDF**.
7. **Subli Live**: start webcam → draw a **Restricted Zone** → motion inside it
   fires a **real-time alert**.
8. **Command Center**: add camera sources; live/offline status.
9. **⌘K** command palette to jump anywhere.

## The story it tells
VIDEO → UNDERSTANDING → MEMORY → EVENTS → REASONING → SEARCH → EVIDENCE → REPORT
